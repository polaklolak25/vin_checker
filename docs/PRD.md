# Product Requirements Document (PRD): OpenVIN

## 1. Цель проекта
Создать независимую систему проверки автомобилей по VIN-коду с открытым исходным кодом, предоставляющую пользователям быстрый доступ к базовым заводским характеристикам и истории транспортного средства.

## 2. Основные функциональные требования
* **Валидация VIN:** Проверка длины строки (ровно 17 символов), исключение запрещенных букв (I, O, Q) и проверка контрольной суммы по стандарту ISO 3779.
* **Декодер характеристик:** Извлечение информации о годе выпуска, стране-производителе, марке, модели, типе двигателя и комплектации.
* **Интерфейс:** Минималистичный веб-интерфейс с мгновенным выводом результатов в виде структурированного списка.

## 3. Архитектура данных
* **Уровень 1 (Клиент):** Сбор ввода, базовая валидация на стороне браузера.
* **Уровень 2 (Внешние API):** Запросы к открытым государственным и международным базам данных.
* **Уровень 3 (Бэкенд и Кэш — в разработке):** База данных (PostgreSQL) для сохранения уже проверенных VIN с целью снижения нагрузки на внешние API.
