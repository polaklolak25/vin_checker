# OpenVIN (Open Vehicle Identification Number)

> Открытая и независимая архитектура для проверки истории автомобилей и расшифровки VIN-кодов.

## 🚀 О проекте
**OpenVIN** — это инициатива по созданию свободного и прозрачного инструмента для проверки транспортных средств по их 17-значному VIN-коду. Проект объединяет базовую заводскую спецификацию и открывает возможности для агрегации данных об истории эксплуатации автомобилей.

## 🛠 Стек технологий (Текущая версия)
* **Frontend:** HTML5, JavaScript (Vanilla), CSS3.
* **Интерфейс:** Развернуто и доступно через **GitHub Pages**.
* **API:** Интеграция с официальными открытыми источниками (например, NHTSA vPIC) для быстрого декодирования заводских параметров.
